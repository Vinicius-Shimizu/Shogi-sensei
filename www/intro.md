# Resumo

Este trabalho tem como objetivo desenvolver o Shogi-sensei, uma ferramenta para ensinar os fundamen-
tos básicos de shogi para iniciantes. Para tal, foi criado um gerador de exercícios organizados em módulos,
cada um abordando as principais mecânicas do jogo. Além disso, foi implementado um algoritmo que adapta
a distribuição dos módulos nas listas de exercícios de acordo com o desempenho do usuário em cada um
deles. Ao final das listas, um modelo de linguagem de grande escala gera explicações sobre as questões
respondidas incorretamente. O servidor do sistema foi desenvolvido em Python, enquanto a interface foi
implementada utilizando React. Para avaliar a efetividade do Shogi-sensei, foi realizado um experimento
com participantes com pouco ou nenhum conhecimento de shogi, durante o qual foram coletadas métricas
como taxa de acerto e variação da distribuição de probabilidades de seleção atribuídas a cada módulo. Ao
final, os participantes também responderam a um questionário para compartilhar suas impressões sobre o
sistema. Os resultados sugerem que a ferramenta contribuiu positivamente para o aprendizado dos funda-
mentos básicos do jogo. Dessa forma, conclui-se que, embora ainda se encontre em um estágio inicial de
desenvolvimento, o projeto atingiu seu objetivo de oferecer uma ferramenta de apoio ao aprendizado de
shogi para iniciantes.
